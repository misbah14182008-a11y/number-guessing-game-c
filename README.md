# Number Guessing Game in C

A simple beginner-friendly C program where the computer
generates a random number between 1 and 100.

The user keeps guessing until they find the correct number.

## Concepts Used
- Variables
- if-else
- do-while loop
- rand()
- srand()
- time()
- User input
- Counter

## How to Run

Compile:
gcc number_guessing_game.c -o game

Run:
./game
